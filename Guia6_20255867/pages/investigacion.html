Expresiones regulares en JavaScript

Investigación teórica y aplicación en la validación de formularios web

Natalia Jimena Díaz Beltrán · 20255867

Introducción

La validación de datos es una parte importante del desarrollo web, ya que permite comprobar si la información ingresada en un formulario cumple con los requisitos establecidos. Según MDN Web Docs (s. f.-d), la validación realizada en el navegador permite identificar errores y orientar al usuario para corregirlos antes de enviar la información.

Una de las herramientas utilizadas para esta tarea son las expresiones regulares, las cuales permiten definir patrones para identificar y comprobar determinadas combinaciones de caracteres dentro de cadenas de texto (MDN Web Docs, s. f.-a).

¿Qué son las expresiones regulares?

Las expresiones regulares, también conocidas como RegExp o regex, son patrones utilizados para encontrar coincidencias de caracteres en cadenas de texto. En JavaScript, estas expresiones son objetos que permiten realizar búsquedas y trabajar con información textual mediante distintos métodos (MDN Web Docs, s. f.-a).

Su principal característica es que permiten definir una estructura que debe cumplir un texto, sin necesidad de comprobar cada carácter individualmente. Esto facilita actividades como la búsqueda de información, la sustitución de texto y la validación de datos ingresados por los usuarios.

Ejemplo práctico

Si un carnet estudiantil debe contener dos letras seguidas de tres números, una expresión regular puede comprobar que tenga esa estructura.

/^[A-Za-z]{2}[0-9]{3}$/

AB001: formato correcto.
ABC001: formato incorrecto.

¿Cómo funcionan en JavaScript?

Para utilizar expresiones regulares, primero se establece un patrón que describe los caracteres permitidos y su organización. Después, se compara el patrón con una cadena de texto para determinar si existe una coincidencia.

MDN Web Docs (s. f.-a) explica que existen dos formas principales de crear expresiones regulares en JavaScript: utilizando una expresión literal entre barras diagonales o mediante el constructor RegExp. 

// Expresión regular literal
const patron = /abc/;

// Utilizando el constructor RegExp
const patron2 = new RegExp("abc");

Los patrones pueden combinar letras, números y caracteres especiales. Estos últimos permiten establecer condiciones como cantidades de repeticiones, grupos de caracteres y posiciones dentro del texto (MDN Web Docs, s. f.-b).

Principales elementos de una expresión regular

Los siguientes símbolos permiten construir algunos de los patrones más utilizados en JavaScript (MDN Web Docs, s. f.-b).

Símbolo Función
^ Indica el inicio de la cadena.
$ Indica el final de la cadena.
[A-Za-z] Representa letras mayúsculas y minúsculas sin tildes.
[0-9] Representa dígitos del 0 al 9.
{n} Indica una cantidad exacta de repeticiones.
+ Indica una o más repeticiones.
* Indica cero o más repeticiones.
? Indica cero o una repetición.

Métodos para utilizar expresiones regulares

JavaScript proporciona diferentes métodos para trabajar con expresiones regulares. Entre ellos se encuentran test(), exec(), match(), search() y replace(), que permiten comprobar coincidencias, buscar información o reemplazar contenido dentro de cadenas de texto (MDN Web Docs, s. f.-a).

Para la validación de formularios, uno de los métodos más útiles es test(). Este método comprueba si una cadena coincide con una expresión regular y devuelve un valor booleano: true cuando encuentra una coincidencia y false cuando no la encuentra (MDN Web Docs, s. f.-c). 

const regexCarnet = /^[A-Za-z]{2}[0-9]{3}$/;

regexCarnet.test("AB001");  // true
regexCarnet.test("ABC001"); // false

En este ejemplo, el primer valor cumple con las reglas del patrón, mientras que el segundo contiene una letra adicional. Por esa razón, los resultados son diferentes.

Aplicación en formularios web

Las expresiones regulares se utilizan frecuentemente para validar el formato de los datos ingresados en formularios. Pueden ayudar a verificar información como correos electrónicos, códigos de identificación y campos que requieren números o letras en un orden específico.

MDN Web Docs (s. f.-d) señala que la validación del lado del cliente permite ofrecer una respuesta más inmediata al usuario cuando introduce información que no cumple con los requisitos.

En la Guía de Laboratorio N.º 6 se solicita desarrollar una ficha de estudiante que valide siete datos mediante expresiones regulares (Escuela Superior de Economía y Negocios [ESEN], 2026, p. 34).

Nombre completo Letras y espacios, sin números ni caracteres especiales.
DUI Ocho dígitos, guion y un dígito.
NIT Cuatro, seis, tres y un dígito separados por guiones.
Fecha de nacimiento Día, mes y año.
Correo electrónico Formato de correo electrónico.
Edad Únicamente números.

Relación con lo aprendido en clase

La implementación de expresiones regulares puede relacionarse con el uso de funciones y eventos en JavaScript.

En la presentación de la Clase 12, Calderón (s. f., diap. 2) explica que las funciones son bloques de código reutilizables que permiten organizar las instrucciones de un programa.

Asimismo, el método addEventListener() permite asociar una función con un evento específico para que se ejecute cuando dicho evento ocurra (Calderón, s. f., diap. 59).

Por ello, al validar un formulario podemos crear una función que compruebe los datos mediante expresiones regulares y ejecutarla cuando el usuario envíe el formulario.

Relación entre los conceptos

La expresión regular define el patrón, la función realiza la validación y el evento permite ejecutar esa función cuando el usuario interactúa con el formulario.

Ventajas y limitaciones

Una de las principales ventajas de las expresiones regulares es que permiten comprobar estructuras de texto utilizando patrones reutilizables. También facilitan la identificación de errores de formato en los datos ingresados.

Sin embargo, no todas las validaciones pueden resolverse únicamente mediante expresiones regulares. Por ejemplo, comprobar que una fecha exista realmente puede requerir operaciones adicionales.

Además, MDN Web Docs (s. f.-d) advierte que la validación del lado del cliente no sustituye a la validación del servidor, ya que los controles del navegador pueden ser omitidos o manipulados.

Conclusión

Las expresiones regulares son una herramienta importante en JavaScript porque permiten establecer patrones para identificar, analizar y validar cadenas de texto. Su utilización facilita la comprobación de formatos y ayuda a detectar errores al completar formularios.

A través de esta investigación se comprende que las expresiones regulares pueden combinarse con funciones y eventos para desarrollar validaciones más organizadas. También es importante reconocer que comprobar un formato no siempre significa verificar la autenticidad de los datos.
